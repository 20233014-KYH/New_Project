# data/ — 도구 목록

**담당: ① 수집** (정해지면 이름 적기)

여기에 두는 것
- `entries.json`: 도구 하나당 한 건 (이름, 저장소, 분야, 하는 일 한 줄, 라이선스, 확인일, 버전, 상시 토큰)
- 수집 스크립트와 수집 기록 (언제, 어디서, 몇 개)

규칙
- 도구 정보는 링크·설치법·라이선스를 **직접 열어 본 뒤** 올려요.
- 확인 못 한 값은 비워 두고 "확인 안 됨"으로 둬요.
- 형식은 [docs/proposal-ROH.md](../docs/proposal-ROH.md) 6-1장을 따라요.
