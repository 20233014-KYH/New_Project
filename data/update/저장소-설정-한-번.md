# 저장소 설정 한 번 바꾸기 (저장소 주인: 김용현)

매주 월요일 자동 최신화(`.github/workflows/catalog-refresh.yml`)가 **PR까지 만들려면** 저장소 설정 하나를 켜야 해요.
이 설정은 저장소 주인만 바꿀 수 있어서, 다른 팀원은 대신 못 해요.

## 왜 필요한가요
- 자동 최신화는 바뀐 게 있으면 새 브랜치를 올리고 **PR을 만들어서** 사람이 보고 합치게 해요.
- GitHub은 기본으로 "Actions가 PR을 만드는 것"을 막아 둬요. 이게 꺼져 있으면 **브랜치만 올라가고 PR은 안 생겨요.**

## 바꾸는 법 (1분)
1. 저장소 위쪽 **Settings**를 눌러요.
2. 왼쪽 메뉴에서 **Actions → General**을 눌러요.
3. 아래쪽 **Workflow permissions**에서
   - **Read and write permissions**를 고르고
   - **Allow GitHub Actions to create and approve pull requests**에 체크해요.
4. **Save**를 눌러요.

## 잘 됐는지 확인 (선택)
1. 저장소 위쪽 **Actions** → 왼쪽 **카탈로그 자동 최신화**를 눌러요.
2. **Run workflow** → **Run workflow**를 눌러요.
3. 끝나면 둘 중 하나예요.
   - 바뀐 게 있으면 `auto-refresh-날짜` PR이 새로 생겨요.
   - 바뀐 게 없으면 기록에 "바뀐 것 없음"이 나오고 끝나요(이것도 정상).

## 안전한가요
- 이 설정은 **우리 저장소의 자동 작업**에만 해당돼요. 바깥 사람에게 권한을 주는 게 아니에요.
- 자동 작업은 PR만 만들고 **스스로 합치지 않아요.** 합치는 건 항상 사람이 해요.
- 키나 비밀번호를 새로 넣을 필요는 없어요(GitHub이 자동으로 주는 임시 토큰을 써요).
