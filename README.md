# "새로운 프로젝트 시작"

> 오픈소스기반 기초설계 팀 프로젝트 저장소입니다. 지금은 **기획 단계**이고, 팀원들이 방향을 검토하는 중입니다.

## 이 프로젝트는 뭔가요?

Claude를 더 잘 쓰게 해 주는 도구(플러그인, 스킬, MCP 서버 등)를 **내가 이미 쓰는 도구와 비교해서**,
겹치거나 부딪히는 것은 알려 주고 더 쓰면 좋은 것은 추천해 주는 **한국어 웹 서비스**입니다.

(프로젝트 이름은 아직 정하지 않았습니다. 지금은 "AI 도구 인벤토리"라는 가칭을 쓰고 있어요.)

## 왜 만들까요?

- 쓸 만한 도구는 대부분 **영어**로만 설명돼 있어서 찾기도, 이해하기도 어렵습니다.
- 비슷한 도구를 여러 개 설치했다가 **서로 겹치거나 꼬여서** 하나만 쓰게 되는 일이 많습니다.
- 그런데 **설치하기 전에** 이런 걸 알려 주는 곳이 마땅치 않습니다.
- Claude에 **이미 들어 있는 기능**을 모르고 같은 일을 하는 오픈소스를 또 설치하기도 합니다.

## 이렇게 쓰게 됩니다 (예시)

1. 지수는 Claude를 처음 써 봅니다. 사이트에서 "하고 싶은 일"을 고르면 시작용 도구를 추천받습니다.
2. 지수가 쓰는 도구를 **내 도구함**에 담습니다. (사이트에서 직접 고릅니다. 내 컴퓨터를 읽어 가지 않아요.)
3. 새 도구 B를 설치하려고 도구함에 담았더니 "**이미 쓰는 A와 하는 일이 겹쳐요. 하나만 쓰는 걸 권장해요**"라고 알려 줍니다.
4. 이유와 함께 "**AI가 추정한 내용인지, 여러 AI가 같은 판정을 했는지, 사람이 확인했는지**"도 보여 줍니다.
5. 도구함을 보고 "디자인 쪽 도구가 없네요. 이런 도구를 더 써 보세요"처럼 **추가 / 교체 / 정리**를 추천합니다.

> 위 이름(지수, A, B)은 설명을 위한 예시입니다.

## 서비스가 하는 일 한눈에 보기

| 기능 | 설명 |
|---|---|
| 내 도구함 | 쓰는 도구와 써볼 도구를 담아 한 화면에서 봄 |
| 충돌·중복 확인 | 담은 도구끼리 겹치는지, 같이 쓰면 문제가 생기는지 알려 줌 |
| 추천 | 추가(빈 곳 채우기) / 교체(더 나은 대체) / 정리(겹치는 것 빼기) |
| 도구 카드 | 한국어 설명, 설치 방법, 주의할 점, 토큰이 늘지 줄지 방향, 내장 기능과 함께 쓰는 법 |
| 둘러보기 | 효과별 카테고리, 별 수·최근 업데이트순 정렬, 후기 링크와 댓글 |
