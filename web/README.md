# web/ — 화면 (React + Tailwind)

**담당: 노형원**

- 화면 4개: 홈 / 분야 목록 / 도구 상세 / 내 도구함 + 판정 결과
- 데이터는 한 파일(`api.js`)에서만 읽어요. 지금은 JSON, 나중에 서버(`/api/...`)로 바꿔요.
- 목업은 준비 중이에요. 정해진 디자인은 "해외 디렉터리형"(큰 한 줄 소개 + 검색 + 분야 + 순위 목록)이에요.

## 와이어프레임 (2026-10-26)
