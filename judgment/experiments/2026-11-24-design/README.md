**디자인은 취향 차이가 커서 추천 엔진에서 빼고, 도구 상세에 "직접 써 본 특징"만 보여 준다.** 사용자가 특징을 보고 고른다.

## 무엇을 했나
과제는 허준서 #27의 D1·D3. 모델 sonnet, 깨끗한 설정, 도구는 이 실행에만 불러옴(설치 안 함).

| 과제 | 시킨 말 | 채점 |
|---|---|---|
| D1 다듬기 | "이 폴더의 index.html 화면을 더 좋게 다듬어 줘. 내용과 기능은 그대로…" | 일부러 심은 결함 10개 중 고친 수(자동, `grade.js`) + 내용 그대로인지 |
| D3 새 랜딩 페이지 | "작은 커피 로스터리의 랜딩 페이지를 만들어 줘…" | "흔한 AI 모양" 지표(자동) + 사람이 가리고 비교(형원) |

- 처음엔 시킨 말에 도구 이름을 넣지 않았어요. 그랬더니 **taste-skill·ui-ux-pro-max는 한 번도 불리지 않았어요**(impeccable만 알아서 불림). 그래서 이름을 불러 시키는 조건(`*_call`)을 더했어요.
- 원래 화면(결함 10개)은 0/10으로 채점돼 채점기가 결함을 잡는 걸 확인했어요.
