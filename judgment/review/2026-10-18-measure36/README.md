# 36개 도구 실측 + 90쌍 판정 초안 (검수 대기, 2026-10-18)

> **김용현 할 일**: 이 폴더의 판정 초안이 맞는지 검수해 주세요. 방법은 아래 "검수 방법"에 있어요.

## 무엇을 했나요
1. **36개 도구를 하나씩 켜고** Claude Code에 "ok" 한 마디를 2번씩 물어서, **처음 읽는 양(토큰)**을 쟀어요.
   - 같은 시간에 도구를 하나도 안 켠 상태도 처음과 끝에 2번씩 쟀어요. 19,133~19,143으로 거의 같아서 측정 조건이 유지됐어요.
   - 1회차와 2회차의 차이는 대부분 5토큰 이하였어요.
2. **같은 분야 안의 모든 쌍**(분야당 15쌍 × 6분야 = 90쌍)에 판정 초안을 붙였어요.
   - 시험으로 직접 잰 쌍은 그 결과를 썼어요(근거: **실측**).
   - 같은 대상을 다루는 MCP 둘은 문서를 보고 겹침으로 적었어요(근거: **문서**).
   - 나머지는 기능 이름·설명이 얼마나 비슷한지 계산해서 적었어요(근거: **계산**). **이 부분이 가장 틀리기 쉬워요.**

| 칸 | 쓰는 법 |

| 검수_이유·출처 | 왜 그렇게 봤는지 + 근거 링크(README, 문서, 직접 해 본 결과) |

**순서 (위에서부터 하면 돼요)**
1. **겹침 6쌍**: 정말 같은 일을 하는지 확인해요. 화면에 "하나 꺼도 돼요"로 나갈 판정이라 가장 중요해요.
2. **판정 못 함 24쌍**
   - 한쪽이 세션에 읽히는 기능이 없거나(rtk, headroom, ccusage 등) 실측을 못 한 쌍이에요(mcp-toolbox).
   - README를 읽고 판정해 주세요. 예: rtk × headroom은 둘 다 "출력 줄이기"라 겹칠 수 있어요.
3. **기획·작업 방식 분야의 "관계 없음"**
   - superpowers × gstack, superpowers × gsd-core처럼 **둘 다 개발 절차 전체를 정해 주는 도구**인데 계산으로는 "관계 없음"이 나왔어요.
   - 스킬 이름이 서로 달라서 계산이 놓친 것으로 보여요. 이 분야는 특히 직접 봐 주세요.
4. **상황따라 11쌍**: "어떤 상황에서 손해/이득인지" 한 줄로 적어 주세요.
5. 시간이 되면 **실측 쌍 하나를 직접 다시 돌려** 같은 숫자가 나오는지 확인해 주세요. 방법은 `judgment/experiments/` 각 폴더의 README에 있어요.

**판정 뜻 (CLAUDE.md의 5종)**
- **겹침**: 비슷한 일을 해서, 같이 켜면 안 쓰는 쪽도 매번 읽혀요(손해가 확실).
- **상황따라**: 하는 일에 따라 손해일 수도, 이득일 수도 있어요.
- **보완**: 서로 다른 곳을 맡아서 같이 쓰면 좋아요.
- **관계 없음**: 서로 영향이 없어요.
- **고장 확인**: 같이 켜면 실제로 망가지는 게 재현됐어요(아직 0건).

## 주의할 점
- **"처음 읽는 양"만 쟀어요.** 실제로 일을 시켰을 때의 효율은 3쌍만 시험했어요(시험 1·2).
- **키가 필요한 MCP**(Figma, supabase, claude-context)는 가짜 값으로 켜서 도구 목록만 쟀어요.
  - 연결에 실패한 서버도 있어요: containers/kubernetes(설정 파일 없음), dbhub(DB 주소 없음), claude-mem 검색 서버, trailofbits의 zeroize-audit(uvx 필요).
  - 이런 도구는 실제로 쓰면 더 읽힐 수 있어요.
- 마켓플레이스에 플러그인이 여러 개면 **전부 켠 값**이에요. pm-skills 9개, trailofbits 44개, headroom 2개, claude-mem 2개예요.
- **mcp-toolbox는 실측 안 했어요.** Windows 실행 파일이 294MB이고 실제 데이터베이스가 있어야 해요.
- **측정 중에 도구가 사용자 폴더에 남긴 파일**은 `side_effects.md`에 있어요. codegraph의 사용 기록 대기열, Figma MCP의 기본 사용 기록 보내기 같은 것이에요. 허준서 보안 조사에 넘길 내용이에요.
- 버전: Claude Code 2.1.191, 측정일의 각 저장소 최신본(superpowers 7.0.0, ECC 2.2.3 등). impeccable만 이 컴퓨터에 설치된 4.0.4예요.
