# 분야별 비교 축 초안 v0 (준서 조사용, 팀 검토 전)

작성: 김용현 · 상태: **초안**. 이 문서는 "도구마다 같은 분야의 다른 도구보다 어떤 점이 다른지"를 찾을 때 **무엇을 기준으로 볼지**를 정합니다. 분야마다 "좋다"의 뜻이 다르기 때문입니다.

## 쓰는 원칙
1. **"좋다·예쁘다·뛰어나다"라고 쓰지 않습니다.** 대신 **무엇을 하는지, 얼마나 드는지**처럼 확인할 수 있는 것을 씁니다. (`docs/judgment-criteria.md` 3장과 같은 원칙)
2. 값마다 **근거 종류**를 붙입니다: `calc`(코드가 계산) / `doc`(문서·제작자 주장) / `tested`(우리가 직접 확인) / `ai`(AI 추정). 출처는 파일:줄이나 주소로 적습니다.
3. 확인하지 못한 값은 **"확인 안 됨"**이라고 씁니다. 비워 두거나 추측하지 않습니다.
4. 장점은 **"같은 분야의 어떤 도구에 비해"**라고 비교 대상을 함께 씁니다.
5. 토큰이 더 들어도 월등하다는 말은 근거가 `tested`일 때만 씁니다. 제작자 주장은 "제작자 주장"이라고 표시합니다.

- 이미 있는 자료는 다시 조사하지 않아도 됩니다. 위 표의 "이미 있는 자료" 열을 먼저 보세요.
