# judgment/ — 겹침 판정

**담당: ② 판정** (정해지면 이름 적기)

여기에 두는 것
- `compat.json`: 도구 두 개의 관계 (겹침 / 용도별 / 보완 / 관련 없음 / 동작 문제 확인됨)
- `experiments/`: 판정의 근거가 된 시험 기록 (날짜별 폴더)
- 판정 프롬프트와 검수 기록

규칙
- 근거마다 종류를 붙여요: **실측**(우리가 돌려 봄) / **문서**(제작자 주장) / **AI 추정**
- 분석 안 한 조합은 "안전"이 아니라 **"확인된 정보 없음"**이에요.
- 기준은 [docs/judgment-criteria.md](../docs/judgment-criteria.md)를 따라요.
