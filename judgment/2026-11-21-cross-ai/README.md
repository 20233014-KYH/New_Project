# 다른 분야 도구 쌍 540개 AI 판정 (2026-11-21)

같은 분야 90쌍은 팀원이 확인했고(사람 검토), 다른 분야끼리 540쌍은 비어 있었어요. 이걸 AI 두 개로 따로 판정해 맞춰 봤어요.

## 방법
1. `code/build_input.py`: 36개 도구 정보(설명·한국어 소개·기능 목록·역할 범위·처음 읽는 양)와, 같은 분야 때와 같은 방식(기능 설명 TF-IDF)으로 뽑은 "비슷한 기능 후보"를 분야 짝 15묶음(`batches/`)으로 만들어요.
2. `code/run_judge.py`: 같은 지시문(`판정지시문.md`)으로 Claude(sonnet, 깨끗한 설정)와 Codex가 따로 판정해요(`out/`).
   - 시험 삼아 한 묶음을 돌려 보니 Codex가 "대상이 달라 각자 쓸 수 있다"까지 보완으로 판정해서, 보완 기준을 "한쪽의 약점을 다른 쪽이 직접 메울 때만"으로 좁힌 뒤 전부 다시 돌렸어요.
3. `code/merge.py`: 두 판정을 합쳐 `compat.json`(화면·서버 두 벌)에 넣어요.
   - 같으면 그 판정(근거 표시: AI 추정)
   - 다르면 한쪽이라도 겹침·상황따라면 상황따라, 아니면 관계 없음 (보완은 둘 다 동의할 때만, 빼기 추천이 생기는 겹침도 둘 다 동의할 때만)
   - 겹침은 같은 분야와 같은 기준: 두 도구 모두 처음 읽는 양 1,000토큰 이상
   - caveman × superpowers는 직접 시험 기록(2026-10-18)으로 넣음
