## Subagent dispatch requires multi-agent support

Add to your Codex config (`~/.codex/config.toml`):

```toml
[features]
multi_agent = true
```

This enables the multi-agent tools that skills like
`dispatching-parallel-agents` and `subagent-driven-development` use.
Which tools you get depends on the multi-agent version your model
preset selects (current presets run V2; older ones run V1). Trust your
actual tool list over any table ??including this one ??when they
disagree.

- **Spawning:** give children a clean context with
  `spawn_agent {fork_turns: "none"}`; the default `"all"` copies your
  entire transcript into the child. On Codex 0.145+, role files under
  `~/.codex/agents/` attach to isolated forks via `agent_type`.
  Full-history forks accept `model` and `reasoning_effort` overrides
  (only `agent_type` is refused there) ??isolated forks are the SDD
  default for context hygiene, not because overrides require them.
- **Fix rounds:** resume the implementer with `followup_task` ??it
  delivers your message, triggers a turn, and transparently reloads a
  child the harness evicted. Never dispatch a fresh implementer on the
  theory that a spawned agent cannot be messaged again; on V2 it
  always can.
- **Lifecycle:** V2 has no `close_agent`. Finished children are
  evicted automatically when slots are needed; leaving them unclosed
  costs nothing. Only V1 sessions have `close_agent` ??there, close
  reviewers when their review returns, and close each implementer
  after its task's review passes.
- **Model names:** never copy a model name from a skill, table, or old
  session into `spawn_agent` without checking it against your current
  spawn allowlist ??V2 accepts only V2-capable presets and hard-errors
  on the rest.

## Waiting on children

`wait_agent` is an event subscription, not a poll: a long wait wakes
the moment a child produces mailbox activity, with the same latency as
a short one. Short-timeout polling buys nothing and costs a tool call ??and a context rebill ??per poll. In measured sessions, roughly
two-thirds of all wait calls were short polls that timed out.

- While you still have local work, do not wait at all. A completed
  child's final answer is pushed into your mailbox and arrives with
  your next turn.
- When you are genuinely idle with children outstanding, wait in
  bounded stretches: `wait_agent` with `timeout_ms` 300000-600000
  (5-10 minutes). After each stretch ??wake or timeout ??post one
  status line, run `list_agents`, and chase any child that finished
  without reporting. Never stack polls shorter than five minutes; the
  event subscription wakes a bounded stretch just as fast as a short
  one.
- Completion mail cannot wake an idle controller (it is delivered
  without triggering a turn); covering that idle window is
  `wait_agent`'s only job. A stretch that times out with no activity
  is your cue to reconcile, not to shorten the next stretch.

## Model routing on spawns

Every `spawn_agent` you issue ??including when you are yourself a
spawned child running a fan-out ??sets `model` AND `reasoning_effort`
explicitly, per the Model Selection rules of the skill you are
executing. Setting `model` alone is a trap: the child's effort
silently resets to that model's default, not to yours.

Ask your human partner to add a machine-level backstop to
`~/.codex/config.toml` so any spawn that slips through still routes to
a deliberate tier instead of silently inheriting the session's most
expensive model:

```toml
[agents]
default_subagent_model = "<a mid-tier model from your spawn allowlist>"
default_subagent_reasoning_effort = "medium"
```

```bash
GIT_DIR=$(cd "$(git rev-parse --git-dir)" 2>/dev/null && pwd -P)
```

- `BRANCH` empty ??detached HEAD (cannot branch/push/PR from sandbox)

 108: // ---------------------------------------------------------------------------
 109: // Exception capture: redacted $exception with a MANDATORY in-memory
 110: // rate-limiter / deduper. posthog-node has NO built-in exception rate limit, so
 111: // without this an error loop would bill one ingested event per occurrence.
 112: // ---------------------------------------------------------------------------
 113: 
 114: /** Send at most one $exception per fingerprint per this window. */
 115: const ERROR_RATELIMIT_WINDOW_MS = 60_000;
 116: /**
 117:  * Hard cap on the dedupe map size so a pathological stream of UNIQUE
 118:  * fingerprints can't grow it without bound. When exceeded, the least-recently
 119:  * ACTIVE entry (by max(lastSentTs, firstTs)) is evicted (LRU) so a hot,
 120:  * still-firing error isn't evicted ahead of a genuinely stale one. Bounds
 121:  * worst-case memory to O(MAX) small records.
 122:  */
 123: const ERROR_FINGERPRINT_MAX = 500;
 124: 
 125: type ErrorRateState = {
 126:   /** Total occurrences seen this window (including dropped ones). */
 127:   count: number;
 128:   /** First time this fingerprint was seen (used for eviction ordering). */
 129:   firstTs: number;
 130:   /** Last time we actually SENT this fingerprint (0 = never sent yet). */
 131:   lastSentTs: number;
 132: };
 133: 
 134: const errorRateMap = new Map<string, ErrorRateState>();
 135: 
 136: /**
 137:  * Stable fingerprint for an error: type + normalized message TEMPLATE + top
 138:  * stack frame. messageTemplate() collapses varying numbers/ids/quoted values so
 139:  * "User 12 not found" and "User 9999 not found" share one fingerprint. Pure /
 140:  * never throws.
 141:  */
 142: function fingerprintError(type: string, message: string, stack: string): string {
 143:   let topFrame = '';
 144:   try {
 145:     const lines = (stack || '').split('\n').map(l => l.trim()).filter(Boolean);
 146:     // First line is usually the "Type: message" header; the first real frame
 147:     // begins with "at ". Prefer that; fall back to the second line.
 148:     topFrame = lines.find(l => l.startsWith('at ')) ?? lines[1] ?? '';
 149:   } catch (error) {
 150:     const err = error instanceof Error ? error : new Error(String(error));
 151:     logger.warn('SYSTEM', 'Telemetry: stack parse failed while fingerprinting; using empty top frame', undefined, err);
 152:     topFrame = '';
 153:   }
 154:   return `${type}::${messageTemplate(message)}::${topFrame}`.slice(0, 400);
 155: }

 157: /**
 158:  * Rate-limit / dedupe decision for a fingerprint. Returns whether to SEND and
 159:  * the occurrence count to attach. Bounds the map size by evicting the oldest
 160:  * entries. Pure side effect on errorRateMap; never throws.
 161:  */
 162: function applyErrorRateLimit(
 163:   fingerprint: string,
 164:   now: number
 165: ): { send: boolean; count: number } {
 166:   try {
 167:     return applyErrorRateLimitInner(fingerprint, now);
 168:   } catch (error) {
 169:     // On any failure, fail CLOSED (do not send) ??never risk a storm.
 170:     const err = error instanceof Error ? error : new Error(String(error));
 171:     logger.warn('SYSTEM', 'Telemetry: error rate-limit bookkeeping failed; failing closed (event dropped)', undefined, err);
 172:     return { send: false, count: 0 };
 173:   }
 174: }
 175: 
 176: /**
 177:  * Rate-limit bookkeeping proper (map lookup, LRU eviction, window reset).
 178:  * Only ever called from applyErrorRateLimit's try, which fails closed.
 179:  */
 180: function applyErrorRateLimitInner(
 181:   fingerprint: string,
 182:   now: number
 183: ): { send: boolean; count: number } {
 184:   let state = errorRateMap.get(fingerprint);
 185:   if (!state) {
 186:     // Bound the map BEFORE inserting a new key. Evict the least-recently
 187:     // ACTIVE entry (LRU): order by the most recent of lastSentTs / firstTs so
 188:     // a hot, still-firing fingerprint outlives a genuinely stale one.
 189:     if (errorRateMap.size >= ERROR_FINGERPRINT_MAX) {
 190:       let oldestKey: string | null = null;
 191:       let oldestTs = Infinity;
 192:       for (const [k, v] of errorRateMap) {
 193:         const activity = Math.max(v.lastSentTs, v.firstTs);
 194:         if (activity < oldestTs) {
 195:           oldestTs = activity;
 196:           oldestKey = k;
 197:         }
 198:       }
 199:       if (oldestKey !== null) errorRateMap.delete(oldestKey);
 200:     }
 201:     state = { count: 1, firstTs: now, lastSentTs: now };
 202:     errorRateMap.set(fingerprint, state);
 203:     return { send: true, count: 1 };
 204:   }
 205:   state.count += 1;
 206:   if (now - state.lastSentTs >= ERROR_RATELIMIT_WINDOW_MS) {
 207:     state.lastSentTs = now;
 208:     const count = state.count;
 209:     // Reset the occurrence counter for the next window so each sent event
 210:     // carries the count accumulated since the last send.
 211:     state.count = 0;
 212:     return { send: true, count };
 213:   }
 214:   return { send: false, count: state.count };
 215: }

 217: /**
 218:  * Private marker our manual captureException() stamps into additionalProperties
 219:  * (which lands in event.properties before before_send runs). Its presence tells
 220:  * errorBeforeSend "this $exception was ALREADY redacted + rate-limited by the
 221:  * manual path ??pass it through unchanged, just strip this marker so it never
 222:  * ships to PostHog." Events WITHOUT it are SDK autocapture and get the full
 223:  * redaction + rate-limit treatment. Never sent to ingest.
 224:  */
 225: const RATE_LIMITED_SENTINEL = '__cm_rate_limited';

 227: /**
 228:  * Redacts a single frame `filename` (or any path-bearing string): home dir ??~,
 229:  * then absolute path ??basename. Reuses the error-scrub helpers (pure/total).
 230:  * Never throws.
 231:  */
 232: function redactFilename(value: unknown): string {
 233:   try {
 234:     if (typeof value !== 'string' || value.length === 0) return '';
 235:     return redactAbsolutePaths(redactHomeDir(value));
 236:   } catch (error) {
 237:     // Fail to an empty string ??never ship an unredacted path.
 238:     const err = error instanceof Error ? error : new Error(String(error));
 239:     logger.warn('SYSTEM', 'Telemetry: frame filename redaction failed; stripping value entirely', undefined, err);
 240:     return '';
 241:   }
 242: }

 244: /**
 245:  * Fully REDACTS an SDK-autocaptured $exception event in place: posthog-node's
 246:  * addSourceContext reads the user's real source files off disk and attaches
 247:  * raw `context_line`/`pre_context`/`post_context` (SOURCE CODE) plus
 248:  * `filename` to every frame, and the RAW unredacted message in `value`. This
 249:  * strips all of it. Mutates and returns the same props object. Never throws.
 250:  */
 251: function redactAutocapturedExceptionList(props: Record<string, unknown>): void {
 252:   const list = props.$exception_list;
 253:   if (!Array.isArray(list)) return;
 254:   for (const entry of list) {
 255:     if (!entry || typeof entry !== 'object') continue;
 256:     const ex = entry as Record<string, unknown>;
 257:     // Redact the raw message.
 258:     if (typeof ex.value === 'string') ex.value = scrubMessage(ex.value);
 259:     // Redact / strip each frame.
 260:     const trace = ex.stacktrace as { frames?: unknown } | undefined;
 261:     const frames = trace?.frames;
 262:     if (Array.isArray(frames)) {
 263:       for (const frame of frames) {
 264:         if (!frame || typeof frame !== 'object') continue;
 265:         const f = frame as Record<string, unknown>;
 266:         // DELETE raw source lines entirely ??never send them.
 267:         delete f.context_line;
 268:         delete f.pre_context;
 269:         delete f.post_context;
 270:         // Redact the absolute filename to a basename (home ??~).
 271:         if (typeof f.filename === 'string') f.filename = redactFilename(f.filename);
 272:         // function/lineno/colno are lower-risk ??left as-is.
 273:       }
 274:     }
 275:   }
 276: }

 278: /**
 279:  * True when a $exception describes an OS working-directory permission fault
 280:  * (`EPERM`/`EACCES` raised by a `chdir`). Reads the message/type strings both
 281:  * capture paths stamp onto properties (and the SDK's $exception_list). Narrow
 282:  * by design ??it requires the `chdir` syscall AND a permission signal ??so
 283:  * genuine claude-mem failures never match. Never throws.
 284:  */
 285: function isEnvironmentChdirError(props: Record<string, unknown>): boolean {
 286:   try {
 287:     const parts: string[] = [];
 288:     const push = (value: unknown): void => {
 289:       if (typeof value === 'string') parts.push(value);
 290:     };
 291:     push(props.$exception_message);
 292:     push(props.$exception_type);
 293:     push(props.error_message);
 294:     push(props.error_type);
 295:     const list = props.$exception_list;
 296:     if (Array.isArray(list)) {
 297:       for (const entry of list) {
 298:         if (entry && typeof entry === 'object') {
 299:           push((entry as Record<string, unknown>).value);
 300:           push((entry as Record<string, unknown>).type);
 301:         }
 302:       }
 303:     }
 304:     const haystack = parts.join(' ');
 305:     if (!/chdir/i.test(haystack)) return false;
 306:     return /\b(?:EPERM|EACCES)\b|operation not permitted|permission denied/i.test(haystack);
 307:   } catch {
 308:     return false;
 309:   }
 310: }

 312: /**
 313:  * before_send hook applied to the worker client. It ONLY governs $exception
 314:  * events; every other event passes through unchanged.
 315:  *
 316:  * posthog-node runs before_send for BOTH our manual captureException() events
 317:  * AND the SDK's uncaught-exception autocapture, so this hook MUST distinguish
 318:  * them:
 319:  *
 320:  *  - MANUAL (carries RATE_LIMITED_SENTINEL): already redacted by scrubError and
 321:  *    already rate-limited/counted by captureException's applyErrorRateLimit
 322:  *    call. Re-running the limiter here would double-count (corrupting
 323:  *    occurrence_count) and split the fingerprint keyspace. So we pass it through
 324:  *    UNCHANGED, only deleting the private sentinel so it never reaches ingest.
 325:  *
 326:  *  - AUTOCAPTURE (no sentinel): posthog-node's addSourceContext has attached the
 327:  *    user's RAW source code (context_line/pre_context/post_context) and the RAW
 328:  *    unredacted message + absolute filenames. We FULLY REDACT the
 329:  *    $exception_list, force $process_person_profile:false, then apply the
 330:  *    fingerprint rate-limiter (returning null drops duplicates before billing).
 331:  *
 332:  * NEVER throws. On ANY error we return null (DROP) rather than risk shipping an
 333:  * unredacted autocaptured event ??failing closed is the safe one-way-door
 334:  * default here. The error-scrub helpers are pure/total so this is belt-and-
 335:  * suspenders.
 336:  */
 337: function errorBeforeSend(event: EventMessage | null): EventMessage | null {
 338:   try {
 339:     if (!event || typeof event !== 'object') return event;
 340:     const ev = event;
 341:     if (ev.event !== '$exception') return event;
 342: 
 343:     const props = (ev.properties ?? {}) as Record<string, unknown>;
 344: 
 345:     // Drop OS working-directory permission faults (EPERM/EACCES on chdir).
 346:     // These are environment errors ??e.g. a Windows worker whose inherited cwd
 347:     // is an ACL-locked Microsoft Store directory, which makes cross-spawn's
 348:     // post-spawn cwd restore throw ??not claude-mem defects, so they only add
 349:     // noise to error tracking. The daemon pins its cwd to the data dir at boot
 350:     // (pinDaemonWorkingDirectory, #3252), which prevents the common case; this
 351:     // catches any residual variant. Runs ahead of the sentinel branch so it
 352:     // covers BOTH the manual (captureException) and SDK-autocapture paths.
 353:     if (isEnvironmentChdirError(props)) return null;
 354: 
 355:     // MANUAL path: already redacted + counted. Strip the sentinel and pass
 356:     // through unchanged ??do NOT re-redact or re-run the limiter.
 357:     if (props[RATE_LIMITED_SENTINEL]) {
 358:       try {
 359:         delete props[RATE_LIMITED_SENTINEL];
 360:         ev.properties = props;
 361:       } catch {
 362:         /* best-effort marker strip */
 363:       }
 364:       return event;
 365:     }
 366: 
 367:     // AUTOCAPTURE path (no sentinel): redact the raw source/message the SDK
 368:     // attached BEFORE anything else, so even an early return can't leak.
 369:     redactAutocapturedExceptionList(props);
 370:     props.$process_person_profile = false;
 371:     ev.properties = props;
 372: 
 373:     // Derive a fingerprint from the (now-redacted) attached data. posthog-node's
 374:     // autocapture stamps $exception_list; fall back to type/message props.
 375:     let type = 'Error';
 376:     let message = '';
 377:     let stack = '';
 378:     try {
 379:       const list = props.$exception_list;
 380:       if (Array.isArray(list) && list[0] && typeof list[0] === 'object') {
 381:         const first = list[0] as Record<string, unknown>;
 382:         if (typeof first.type === 'string') type = first.type;
 383:         if (typeof first.value === 'string') message = first.value;
 384:         const trace = (first.stacktrace as { frames?: unknown[] } | undefined)?.frames;
 385:         if (Array.isArray(trace) && trace.length > 0) {
 386:           stack = 'at ' + JSON.stringify(trace[trace.length - 1]).slice(0, 200);
 387:         }
 388:       }
 389:     } catch {
 390:       /* fall through to prop-based fingerprint */
 391:     }
 392:     if (typeof props.$exception_type === 'string') type = props.$exception_type;
 393:     if (typeof props.$exception_message === 'string') message = props.$exception_message;
 394: 
 395:     // fingerprintError already applies messageTemplate internally ??pass the
 396:     // raw (redacted) message, do not pre-template it (S1).
 397:     const fingerprint = fingerprintError(type, message, stack);
 398:     const decision = applyErrorRateLimit(fingerprint, Date.now());
 399:     if (!decision.send) return null; // dropped before ingest ??not billed
 400:     try {
 401:       props.occurrence_count = decision.count;
 402:       ev.properties = props;
 403:     } catch {
 404:       /* property attach is best-effort */
 405:     }
 406:     return event;
 407:   } catch {
 408:     // Fail CLOSED: dropping is strictly safer than risking an unredacted leak.
 409:     return null;
 410:   }
 411: }

 413: /**
 414:  * Capture a REAL exception to PostHog Error Tracking ($exception) with the
 415:  * error message + trimmed stack REDACTED by error-scrub.ts. Fire-and-forget,
 416:  * synchronous, never throws, never blocks. Ordering mirrors captureEvent:
 417:  *
 418:  *   1. Consent gate (same hasConsent() as analytics) AND the error kill-switch
 419:  *      (CLAUDE_MEM_TELEMETRY_ERRORS) ??either off ??nothing happens.
 420:  *   2. Shutdown latch ??late errors are dropped, not queued into a dead client.
 421:  *   3. Redact the error (error-scrub: allow-then-redact, NOT the property
 422:  *      whitelist ??that would drop free-form text).
 423:  *   4. Rate-limit / dedupe by fingerprint ??at most one send per fingerprint
 424:  *      per window; occurrence count attached. Mandatory: no unbounded stream.
 425:  *   5. Optional structured context goes through scrubProperties (the same
 426:  *      deny-by-default whitelist as everything else). Error text/stack are the
 427:  *      ONLY values that take the error-scrub path.
 428:  *   6. Debug mode prints to stderr and sends nothing.
 429:  *   7. client.captureException(error, distinctId, additionalProperties):
 430:  *      $process_person_profile:false (no person profile for $exception) plus the
 431:  *      redacted fields + whitelisted context.
 432:  *
 433:  * SDK signature (verified node_modules/posthog-node/dist/client.d.ts:1031):
 434:  *   captureException(error: unknown, distinctId?: string,
 435:  *     additionalProperties?: Record<string|number, any>, ...): void
 436:  * distinctId is the 2nd positional arg; directives like
 437:  * $process_person_profile go in additionalProperties (3rd arg).
 438:  */
 439: export function captureException(
 440:   err: unknown,
 441:   ctx?: Record<string, unknown>
 442: ): void {
 443:   try {
 444:     captureExceptionInner(err, ctx);
 445:   } catch (error) {
 446:     // Exception capture must NEVER propagate to its caller (esp. the logger).
 447:     // logger.warn is safe here: only logger.error re-enters this module via
 448:     // the error sink.
 449:     const failure = error instanceof Error ? error : new Error(String(error));
 450:     logger.warn('SYSTEM', 'Telemetry: captureException failed; $exception dropped', undefined, failure);
 451:   }
 452: }

 454: /**
 455:  * Scrub ??rate-limit ??send pipeline for captureException. Only ever called
 456:  * from captureException's try, which swallows anything this raises.
 457:  */
 458: function captureExceptionInner(
 459:   err: unknown,
 460:   ctx?: Record<string, unknown>
 461: ): void {
 462:   if (isShutdown || !hasConsent() || !isErrorTelemetryEnabled(process.env)) {
 463:     return;
 464:   }
 465: 
 466:   const scrubbed = scrubError(err);
 467:   const fingerprint = fingerprintError(scrubbed.type, scrubbed.message, scrubbed.stack);
 468:   const decision = applyErrorRateLimit(fingerprint, Date.now());
 469:   if (!decision.send) {
 470:     return;
 471:   }
 472: 
 473:   // Structured context (NOT the message/stack) goes through the whitelist.
 474:   const whitelistedContext = scrubProperties({
 475:     ...buildBaseProperties(),
 476:     ...(ctx ?? {}),
 477:   });
 478: 
 479:   const additionalProperties: Record<string, unknown> = {
 480:     ...whitelistedContext,
 481:     // No person profile for exceptions (anti-pattern guard) ??same directive
 482:     // as high-volume operational events in captureEvent.
 483:     $process_person_profile: false,
 484:     // Redacted free-form error fields. These are NOT user-identifying and
 485:     // bypass the property whitelist by design (error-scrub already redacted
 486:     // home dir, paths, URLs, emails, keys, tokens).
 487:     $exception_message: scrubbed.message,
 488:     $exception_type: scrubbed.type,
 489:     error_message: scrubbed.message,
 490:     error_type: scrubbed.type,
 491:     error_stack: scrubbed.stack,
 492:     occurrence_count: decision.count,
 493:     // Private sentinel: tells errorBeforeSend this $exception is ALREADY
 494:     // redacted + rate-limited here, so before_send must NOT re-run the limiter
 495:     // (which would double-count occurrence_count and split the keyspace).
 496:     // before_send deletes it so it never ships to PostHog. (B1 fix.)
 497:     [RATE_LIMITED_SENTINEL]: true,
 498:   };
 499: 
 500:   if (process.env.CLAUDE_MEM_TELEMETRY_DEBUG === '1') {
 501:     process.stderr.write(
 502:       '[telemetry] ' + JSON.stringify({ event: '$exception', additionalProperties }) + '\n'
 503:     );
 504:     return;
 505:   }
 506: 
 507:   // Pass a redacted Error (not the raw one) so the SDK never re-derives an
 508:   // un-redacted stack/message: the SDK reads .message/.stack/.name off the
 509:   // object we hand it.
 510:   const safeError = new Error(scrubbed.message);
 511:   safeError.name = scrubbed.type;
 512:   safeError.stack = scrubbed.stack || `${scrubbed.type}: ${scrubbed.message}`;
 513: 
 514:   getClient().captureException(safeError, getOrCreateInstallId(), additionalProperties);
 515: }

 522:  *   2. Whitelist scrub ??only allowed primitive properties survive.
 523:  *   3. Debug mode (CLAUDE_MEM_TELEMETRY_DEBUG=1) ??print payload to stderr,
 524:  *      send nothing.

 526:  *

 233: const MAX_STRING_LENGTH = 200;

 235: /**
 236:  * Copies whitelisted primitive values from props into scrubbed, truncating
 237:  * strings to MAX_STRING_LENGTH. Extracted so scrubProperties' try stays small.
 238:  */
 239: function copyAllowedProperties(
 240:   props: Record<string, unknown>,
 241:   scrubbed: Record<string, string | number | boolean>
 242: ): void {
 243:   if (!props || typeof props !== 'object') return;
 244:   for (const key of Object.keys(props)) {
 245:     if (!ALLOWED_PROPERTY_KEYS.has(key)) continue;
 246:     const value = props[key];
 247:     if (typeof value === 'string') {
 248:       const truncated = value.length > MAX_STRING_LENGTH ? value.slice(0, MAX_STRING_LENGTH) : value;
 249:       // Allowed keys are supposed to be enums/counters, but a call site can
 250:       // still stuff a URL-shaped token into e.g. `endpoint`. Run the error
 251:       // redaction pipeline so query/userinfo/assignment secrets cannot ride
 252:       // along on a whitelisted key.
 253:       scrubbed[key] = redactText(truncated);
 254:     } else if (typeof value === 'number' && Number.isFinite(value)) {
 255:       scrubbed[key] = value;
 256:     } else if (typeof value === 'boolean') {
 257:       scrubbed[key] = value;
 258:     }
 259:     // Everything else (objects, arrays, functions, null, undefined,
 260:     // NaN/Infinity, symbols, bigints) is dropped silently.
 261:   }
 262: }
 263: 
 264: /**
 265:  * Filters properties down to whitelisted keys with primitive values only.
 266:  * Strings are truncated to 200 chars. Objects, arrays, functions, null,
 267:  * undefined, and non-finite numbers are dropped. Pure, never throws.
 268:  */
 269: export function scrubProperties(
 270:   props: Record<string, unknown>
 271: ): Record<string, string | number | boolean> {
 272:   const scrubbed: Record<string, string | number | boolean> = {};
 273:   try {
 274:     copyAllowedProperties(props, scrubbed);
 275:   } catch {
 276:     // Never throw from the scrubber ??worst case we send fewer properties
 277:   }
 278:   return scrubbed;
 279: }
