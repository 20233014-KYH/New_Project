## 다시 돌리는 법
각 폴더 `code/`의 `run_*.py`. 깨끗한 환경(시험용 설정 폴더 `~/.claude-clean`, 전역 CLAUDE.md 제외)에서 정해 둔 명령만 허용하고 인터넷은 막고 돌려요. 자세한 조건은 각 스크립트 맨 위 설명에 있어요.
- 대화 기록 원본(`*.jsonl`), 작업 폴더(`_cwd*`), 내려받은 프로그램(gradio 코드, semgrep, 브라우저)은 크기 때문에 올리지 않았어요.
