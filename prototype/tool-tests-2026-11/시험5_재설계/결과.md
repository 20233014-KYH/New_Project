# 시험 5: 도구가 맡는 상황으로 다시 시험 (2026-11-13)

설계와 이유는 `원인분석_재시험설계.md`. 깨끗한 환경, 각 3번, 정해진 규칙 채점(AI 채점 없음), 모델 sonnet.
사용량 한도에 걸려 끊긴 실행은 `results_*/_failed_ratelimit/`에 옮기고 다시 돌렸다.

## 한 줄 결론
**도구가 맡는 상황으로 바꾸고 과제를 키워도, 기본 Claude가 대부분 거의 만점이었다.**
차이가 보인 곳은 **"압축된 실제 배포 사이트에서 화면 테스트 만들기"(playwright가 더 정확하고 싸고 빠름)** 하나뿐이고, 그 차이도 작다.
→ 추천 문장은 "이 도구가 결과를 더 좋게 한다"가 아니라 **"이 상황에선 기본으로 충분 / 이 도구는 ○○ 방식이 필요할 때"**로 써야 한다.

### R3. 화면 테스트 만들기 (playwright / chrome-devtools)

| 사이트 | curl로 코드 받아 읽기 | playwright | chrome-devtools |

- 압축된 실제 배포 사이트에서만 playwright가 조금 나음(더 정확·더 빠름·토큰 적음).
- 처음 채점기는 명령을 글자 단위로 쪼개는 문제로 전부 실패로 나왔음 → 목록으로 넘기게 고치고, 직접 쓴 정답 테스트로 채점기부터 검증(정상 통과 + 고장 4/4).

### R4. 막연한 새 아이디어 ("학과 중고 전공책 거래 앱")
| 방식 | 도구 없음 | 계획 모드 | superpowers | gstack /office-hours (정식 설치) |
|---|---|---|---|---|
| 한 번 답하고 끝(8점) | 8, 6, 7 | 7, 7, 6 | 7, 7, 7 | 7, 6, 5 |
| **5번 주고받기(실제 쓰는 방식, 10점)** | 10, 9, 9 | 9, 9, 9 | 10, 9, 7 | 9, 9, 7 |
| 토큰(5번 주고받기) | 약 21만 | 30만~51만 | 약 25만 | 65만~126만 |
- gstack은 처음엔 명령 실행이 막혀 "기능 축소 상태"로 돌았음 → 형원 허락(끝나면 되돌림)으로 실제 설정 폴더에 설치하고 다시 돌림. 정식 설치에서도 결과는 비슷, 토큰은 3~6배.
- gstack은 목표(창업/팀플)를 먼저 묻고 질문을 하나씩 던짐 — 대화 방식은 확실히 다름. 하지만 정해 둔 항목으로는 더 많이 짚지 않았음.
- **채점 규칙 실수 1건:** '판매자·구매자 동시 확보'를 '닭과 달걀·초기 매물' 같은 말만 보게 해서 gstack의 "공급은 이미 있다 / 누구부터 모을지" 표현을 놓쳤음 → 모든 조건에 넓혀 다시 채점(위 표는 고친 뒤 점수).
- 항목 채점은 글이 길수록 유리함(도구 없음 답이 1.1만~1.4만 자, gstack은 약 6~7천 자). 질은 사람이 블라인드로 보는 게 맞음 → 팀원 블라인드 비교로 넘김.

## 왜 여전히 차이가 작은가
1. **기본 Claude Code가 이미 그 일을 함:** 규칙을 파일로 남기기, 큰 코드에서 grep으로 같은 패턴 찾기, 페이지 코드 받아 읽기를 도구 없이도 스스로 함.
2. **스킬은 "설치"만으로는 거의 안 쓰임:** trailofbits는 이름을 불러야 썼음. 설치만 한 조건은 토큰만 늘어남.
3. **연구 결과와 같은 방향:** SkillsBench에서도 소프트웨어 개발 분야는 스킬 효과가 가장 작았음(+4.5%p). 모델이 이미 잘 아는 분야라서.

## 추천 문장 초안 (시험 확인)
- **보안·같은 버그 더 찾기:** 기본으로 충분(작은 코드·gradio 772개 파일 모두). trailofbits는 결과 같고 토큰 1.5~2배. Semgrep·CodeQL 규칙 작성 같은 *절차*가 팀 규칙으로 정해져 있을 때만.
- **화면 테스트 만들기:** 코드를 볼 수 있으면 기본으로 충분. **코드 없이 압축된 배포 사이트만 있을 때는 playwright가 조금 더 정확하고 싸다.**
- **새 아이디어 기획:** 기본·계획 모드로 충분. gstack /office-hours는 결과는 비슷하고 토큰 3~6배 — *질문을 하나씩 받으며 생각을 정리하는 대화 방식*을 원할 때.
- **여러 날 작업:** 기본도 규칙을 파일로 남겨 지킴. superpowers가 이번 시험에서 유일하게 3번 모두 만점(차이는 작음, 토큰 약 1.3배).
